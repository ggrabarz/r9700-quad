# SlimSAS SFF-8654 to NVMe cable

<p class="muted"><strong>€40.00 estimate</strong> · not a listed price · Gen4 x4 adapter. Used in <a href="../../builds/b-capacity/">B</a>.</p>

## What it is

A cable/adapter from the ASRock’s **SlimSAS SFF-8654** header to an M.2 NVMe socket, for the two Gen4 members of the 6× Gen4 array. Two are used in build B.

The price is an **estimate**, not a listed offer.

## Specifications

| Feature | Detail |
|---|---|
| Host side | SlimSAS SFF-8654 (x4 PCIe) |
| Device side | M.2 NVMe socket |
| Generation | Gen4 x4 |
| Length | usually 0.5–1 m |
| Price | **€40.00 estimate** |

## Assessment

<div class="pros-cons" markdown>
<div markdown>
### <span class="good">Strengths</span>

- **Adds two NVMe drives** to the 6× Gen4 build without a carrier.
- **Cheap** relative to a 4× M.2 carrier.
- **Moves the drives off the board** into the 2.5" bays.
- **Gen4 is easier on cable signal integrity** than Gen5.
</div>
<div markdown>
### <span class="bad">Weaknesses</span>

- **Price is an estimate**; exact sourcing is not priced.
- **Gen4 only**; not for a Gen5 array.
- **No hot-swap.**
- **Only build B uses it**; the 3× Gen5 and 4× Gen4 builds do not.
</div>
</div>
