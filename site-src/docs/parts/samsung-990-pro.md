# Samsung 990 PRO 1 TB

<p class="muted"><strong>€262.00</strong> · Alternate DE · PCIe 4.0 x4, 1 TB. Used in <a href="../../builds/b-capacity/">B</a> and <a href="../../builds/c-value/">C</a>.</p>

## What it is

Samsung’s Gen4 flagship, 1 TB, PCIe 4.0 x4. It is the array drive for the 6× Gen4 capacity build and the 4× Gen4 value build. At €262 it is €2 cheaper than the Gen5 9100 PRO, but slower and cooler.

## Specifications

| Feature | Detail |
|---|---|
| Capacity | 1 TB |
| Interface | PCIe 4.0 x4, NVMe |
| Sequential read / write | 7,450 / 6,900 MB/s |
| 4K random IOPS | 1.2M read / 1.55M write |
| Form factor | M.2 2280 |
| Price | **€262.00** |

## Pros

<div class="pros-cons" markdown>
<div markdown>
### <span class="good">Pros</span>

- **€262 per TB**, the cheapest array drive.
- **Gen4 thermals** are easier under the GPUs than Gen5.
- **M.2 2280**, fits every M.2/MCIO/SlimSAS adapter.
- **The 6× Gen4 array is ~44–45 GB/s and ~7.2M 4K IOPS.**
</div>
<div markdown>
### <span class="bad">Cons</span>

- **Gen4**, not Gen5; ~7.45 GB/s per drive.
- **€2 cheaper than the 9100 PRO** — there is almost no price reason to choose it.
- **No PLP**; RAID 0 + consumer SSD.
- **1 TB per drive**; the 6 TB option needs six.
</div>
</div>
