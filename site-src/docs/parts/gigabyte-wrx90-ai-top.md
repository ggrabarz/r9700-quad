# Gigabyte WRX90 AI TOP

<p class="muted"><strong>TBD</strong> · announced 2026-10-30, no retail price or offers at the snapshot · the Gigabyte-native WRX90/IPMI alternative.</p>

## What it is

Gigabyte’s WRX90 board for the AI TOP line: native WRX90, 8 RDIMM/2 TB, seven x16 slots, AST2600 BMC/IPMI, 32+3+3+3 VRM, 14-layer PCB, active memory cooling, two Gen5 M.2 + one Gen4 M.2 + two MCIO 8i, four SATA, dual 10G.

It is the Gigabyte-native WRX90/IPMI alternative to the ASRock and ASUS. It does **not** restore four Gen5 M.2 sockets: the MCIO 8i port shares bandwidth with the two Gen5 M.2 slots, so a four-drive RAID 0 is 3 Gen5 + 1 Gen4, the same as the ASRock.
