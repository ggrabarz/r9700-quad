# Samsung 870 EVO 4 TB

<p class="muted"><strong>€665.00</strong> · Alternate DE · 4 TB SATA SSD. Used in every build as OS + archive/image.</p>

## What it is

A 4 TB SATA SSD for the OS, model/tokenizer/pack archive and — in the 3 TB array builds — a full image of the RAID 0. The usable space is ~3.6 TB, so the 3 TB array fits; the 4 TB and 6 TB arrays do not.

## Specifications

| Sequential | ~560 / 530 MB/s |

| €/TB | ~€166 |

## Assessment

<div class="pros-cons" markdown>
<div markdown>
### <span class="good">Strengths</span>

- **4 TB for €665**, cheap cold storage per TB.
- **Fits a full image of the 3 TB array** (3.6 TB usable).
- **SATA**, so it does not consume an NVMe port.
- **The OS can live here**, leaving the array purely for models.
</div>
<div markdown>
### <span class="bad">Weaknesses</span>

- **SATA speed**; not a working-set drive.
- **4 TB cannot image the 4 TB/6 TB arrays**; those need the 8 TB HDD.
- **Consumer SSD**, no PLP.
- **€665 is still a real line** in the BOM.
</div>
</div>
