# 140 mm PWM case fan

<p class="muted"><strong>€15.00 estimate</strong> · Fractal/Arctic class · bottom/rear airflow. Used in every build.</p>

## What it is

A 140 mm PWM case fan for the bottom intake and rear exhaust. The Meshify 2 XL includes three 140 mm fans; the build adds three more for the M.2/GPU zone and positive pressure.

## Specifications

| Feature | Detail |
|---|---|
| Size | 140 mm |
| Connector | 4-pin PWM |
| Airflow | ~60–80 CFM class |
| Noise | ~20–30 dBA class |
| Price | **€15.00 estimate** |

## Pros

<div class="pros-cons" markdown>
<div markdown>
### <span class="good">Pros</span>

- **Cheap** and easy to replace.
- **Bottom intake** feeds the M.2/MCIO drives and the GPU zone.
- **PWM** follows the motherboard curve.
- **Positive pressure** reduces dust.
</div>
<div markdown>
### <span class="bad">Cons</span>

- **Price is an estimate**, not a listed offer.
- **Noise adds up** with six-plus fans.
- **Cable routing** in a big case takes time.
- **Not a static-pressure fan**; fine for case airflow, not for a radiator.
</div>
</div>
